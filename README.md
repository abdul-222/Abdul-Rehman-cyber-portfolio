# Abdul Rehman — Cyber Security Portfolio

A responsive personal portfolio website built with HTML and CSS, with a small amount of JavaScript for the mobile navigation menu. It works locally in Microsoft Edge and does not require a server, external libraries, or an internet connection.

## Files

- `index.html` — page content and mobile menu behaviour
- `style.css` — dark navy and blue styling and responsive layout
- `cv.pdf` — add your own CV PDF here (not included in this package)

## Open the website locally in Microsoft Edge

1. Extract the downloaded ZIP file.
2. Open the extracted `abdul_rehman_cyber_portfolio` folder.
3. Copy your CV PDF into this folder and rename it exactly `cv.pdf`.
4. Double-click `index.html`. If it opens in VS Code, right-click the file in File Explorer, choose **Open with**, and select Microsoft Edge.
5. If you edit either file in VS Code, save with **Ctrl+S**, then refresh Edge with **Ctrl+R**.

The website will display even if you have not added `cv.pdf`; the CV download link will only work once the PDF is present.

## Personalise before publishing

- Verify the degree dates and your current study/graduation status. The supplied CV listed September 2025–June 2026, which may need updating.
- Confirm the exact status and award titles for CCNA semesters and CyberOps Associate. Do not describe coursework as a full professional certification unless you hold that credential.
- Update project cards so they accurately describe work you have actually completed. Add GitHub links or screenshots only when ready.
- Review whether you want your phone number and email visible to everyone on the public internet.
- Add your real LinkedIn and GitHub profile URLs when available.
- Check all text for accuracy before sharing the site with employers.

## Publish online later

One free option is GitHub Pages. Create a GitHub repository, upload `index.html`, `style.css`, and the CV PDF only if you want the CV to be public, then enable Pages in the repository settings. Anyone who can access the public website may be able to view or download the published CV.
